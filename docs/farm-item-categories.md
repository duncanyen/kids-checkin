# 商店與倉庫分類

兩個頁面使用相同的木製分類頁籤：「雞」、「武器」、「雞舍」、「其他」。分類規則與頁籤外觀共用 `js/farm/item-categories.js`。

| 分類 | 商店買進 | 商店賣出 | 倉庫 |
| --- | --- | --- | --- |
| 雞 | 母雞、烏骨雞、布雷斯雞 | 三種雞隻及各自的雞蛋 | 雞舍中各品種隻數、庫存雞蛋 |
| 武器 | 狼牙棒、雙手斧 | 已卸下的狼牙棒 | 持有的武器，標示配備狀態 |
| 雞舍 | 中級、高級；特級、頂級顯示即將推出 | 提示升級後直接使用、無法賣出 | 目前雞舍名稱與已用／可養隻數 |
| 其他 | 倉庫容量擴充、咕咕活力散 | 菜蟲、蚯蚓、狼牙、虎皮、龍麟、猩猩尖牙 | 倉庫容量資訊、金幣、飼料、活力散與戰利品 |

「中雞舍／大型雞舍」的顯示名稱統一為中級雞舍／高級雞舍。原有 Lv.2／Lv.3 的 3000／10000 金幣價格與 10／20 隻容量不變。依使用者確認，特級與頂級先顯示為即將推出，不設定售價、容量或開放購買，點選亦不會扣錢或開啟交易。

商店每分類每頁最多六項，買進、賣出各自記住每個分類的頁數；倉庫每分類每頁最多八項，同樣獨立記頁。只有多頁時才顯示上一頁、下一頁及頁碼。超過邊界不會跳頁；物品減少會自動回到仍存在的最後一頁，空分類有說明。

倉庫的雞隻、雞舍與容量為目前農場的資訊卡，不是額外庫存、不占容量，不能餵食、丟棄或重複配備。雞隻買賣仍到商店操作，武器配備與飼料餵食照常保留。切換倉庫分類／頁面會關閉舊操作面板，避免操作到上一個分類的物品。

驗證：

- `node tests/farm-item-categories.cjs`：真實 Phaser，分類的商品與庫存內容、買賣切換、雞舍名稱、即將推出不能購買、分類內分頁／獨立頁數／空分類／數量減少後回頁，以及舊操作面板關閉。也用額外武器設定測試日後增加商品的分頁。
- `node tests/farm-weapons.cjs`、`node tests/farm-poultry.cjs`：配備／買賣與混養／餵食／收蛋回歸。

預設本機站台 http://127.0.0.1:8012。所有測試使用隔離的 Firestore，不存取正式資料。
