# 寶箱批次開啟

## 玩家操作

倉庫 → 寶箱 → 點選寶箱卡 → 勾選寶箱（或全選本頁）→ 開啟選取。
每批最多 20 箱，每箱仍可單獨開啟。批次共用一次動畫與結果視窗，合計顯示金幣與同類獎勵數量。
「我的寶箱」只查詢待開啟寶箱，不顯示開箱紀錄；後端保留原有結算資料供防重與結果恢復。

## 交易

新增既有 gameOpsFarmTransaction 的 openChests 動作，接受 1–20 個不同 chestIds。
依既有 Chests.open 驗證歸屬、鎖定快照、戰鬥狀態與交付規則；每箱使用獨立亂數抽取金幣。
所有箱子的發獎、寶箱狀態與收據共用一筆 Firestore 原子交易。倉庫或雞舍容量不足時整批不變。
已開啟寶箱回傳原結果；重送、跨裝置及重疊批次不會重複發獎。重播收據回傳目前農場餘額，避免回退。
逾時保留原選取與既有 requestId；關閉再開啟時先提供「確認上次開箱結果」，不另選新批次。
