# 成長森林：日期欄位、篩選與家長紀錄版面

日期：2026-11-06（台灣）。

## 日期欄位與篩選

- 考試日期、閱讀日期與各紀錄篩選的開始／結束日期共用緊湊日期欄位，寬度依固定日期格式配置，不再拉滿整列。
- 原生日期輸入設定 `min-inline-size:0` 與可用寬度上限，避免窄螢幕被日期控制項的固有寬度撐出視窗。考試／閱讀表單的日期保留獨立空間，其他欄位仍依原表單順序排列。
- 篩選順序為類型、狀態／右側考試類型、開始／右側結束日期、科目與書名。狀態與考試類型以成對容器固定閱讀順序；日期成對排列，在特別窄的螢幕必要時依開始、結束順序換行。
- 家長與個人成長紀錄共用這些欄位配置，篩選值、日期語意及 API 不變。

## 家長管理

既有按鈕順序不變：紀錄與審核、成長概覽、獎勵規則、夢想獎勵、兌換申請、積分明細、資料銜接。改為桌面四欄、手機兩欄的等寬排列，維持觸控高度與個人主題配色。

「紀錄與審核」下方清單改為原生 `<details>` 收合區塊：

- 進入時預設關閉；點標題才展開，鍵盤也可操作。
- 展開後清單限制高度並允許內部捲動，保留「載入更多紀錄」，不把整頁一直向下拉長。
- 摘要顯示「已載入 N 筆」，不是冒充全部紀錄總數。
- 同成員的背景更新保留展開狀態及捲動位置；切換管理分頁／成員，或重新進入家長頁時恢復預設收合。
- 套用篩選回到清單頂端，載入更多則保留原位置。過期查詢回應或已離開的畫面不再覆寫新清單。
