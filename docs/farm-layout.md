# 咕咕村落：清晰全景滿版

`assets/farm/farm-panorama.webp` 是依原本 `farm-map.jpg` 繪製的單張 2172×724 全景圖，保留雞舍、雞舍前空地、菜園與溪流的風格，兩側畫成連續森林及草地。由影像工具產生原始 PNG，再無縮放編碼成高品質 WebP（約 1 MB）。窄版畫面實際使用使用者提供的原始直式圖 `farm-map.jpg`；寬畫面則切換為這張同風格全景，不使用模糊、重複拼貼或分開的側邊背景。

## 畫布與控制項

- Phaser 使用 `Scale.RESIZE`，畫布本身填滿 `#game-container`。CSS 沒有額外底圖或模糊濾鏡。
- `viewport.js` 以原有 390×844 為控制項設計座標，設定相機等比例 zoom 並置中於 (195,422)。螢幕變寬時增加可見世界範圍，按鈕與角色不會因橫向填滿而變形。
- 原圖與全景圖均採等比例 cover；窄版畫面顯示原始農莊，寬畫面使用全景並可見更多左右景色。一般手機橫／直向及桌面均保留雞舍、42 個蔬菜點擊區與操作按鈕。
- 村落搜尋框屬於 DOM，使用相機 zoom 換算定位，與其餘控制項共用設計座標。通知按鈕維持螢幕右下角。

## 場景對齊

`scenery.js` 中的參考座標維持原有 720×1280 地圖的操作語意，透過全景圖的雞舍、入口與六排菜園地標對應至新圖。雞舍點擊區、雞蛋、看板、42 個蔬菜點擊區、母雞散步空地、天氣燈光共用相同座標轉換。

視窗縮放及切換原圖／全景時，不重啟場景、不重新抽取首領。相機即時更新；需要改變底圖 cover 比例時，重新對齊操作區、角色及移動目標，既有戰鬥時限保持不變。商店、倉庫及村落也使用同一相機設定，介面保持原有比例。

## 驗證

- `tests/farm-mail-browser.cjs`：390×844、1440×900、844×390，畫布覆蓋遊戲區、單張全景比例不變、底圖覆蓋視窗、控制項不被橫向拉寬，以及通知完整流程。
- `tests/farm-map.cjs`：本家／拜訪的雞舍點擊、42 個菜園區域及生蛋動畫散步範圍。
- `tests/farm-poultry.cjs`、`tests/farm-public-villages.cjs`：買賣、餵食、偷蛋與跨村落操作回歸。
- `tests/farm-gorilla.cjs`：首領進攻、戰鬥時限、獎勵、失敗結算與擊退後偷蛋。

瀏覽器測試以隔離的 Firebase fixtures 執行，不存取正式資料。

雞舍等級以 `Lv.數字` 標在門框上方既有木匾內，使用深棕文字、不加草地上的背景標籤。直向底圖錨點 `(334,316)`；全景底圖錨點 `(1033,224)`；字級與底圖等比縮放，旋轉時重新定位。
