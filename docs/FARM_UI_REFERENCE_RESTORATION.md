> 本文件保留第一階段 4／13 的歷史結果；後續九個元件已完成 V2 整合，請見 [V2 驗收報告](FARM_UI_V2_ACCEPTANCE.md)。

## 範圍與視覺基準

本次僅更換可精準提取的 UI 圖片，不修改遊戲規則、Firebase 或 Phaser 場景物件。來源為使用者提供的 `gugu_ui_assets.zip`。已實際檢視 PNG；封包包含 1774 × 887 的 `full_sprite_sheet.png`，沒有整張遊戲場景參考圖。

素材包 README 明載「依照參考畫面重新生成」「並非從原圖無損分離」；因此只能確認與**本次素材表**的一致性，不能宣稱已與先前完整場景插畫逐像素一致。

### 需要補齊的素材

1. 三張完整透明資源底板：保留原圖木紋、鉚釘及圖示，不含數字，無鄰接碎片。
2. 空白產蛋木牌：保留雞頭、吊繩、綠葉，不含任何雞種文字或時間殘影。
3. 底部整組無通知紅點版，以及獨立紅點。最好另提供可獨立按壓的五個完整按鈕與無按鈕底座，保留兩端固定件及綠葉。
4. 實際手機場景參考圖及原始尺寸，供場景座標、安全邊距及整體比例驗收。

不得用遮蓋、模糊、生成或補畫猜測被紅點／文字遮住的像素，以免將近似版冒充精準還原。

## Step 3：本次替換

四張 PNG 只從完整素材表裁切與增加透明留白，沒有重繪、調色或插值縮放。三顆側邊圖使用相同 200 × 200 畫布，設定也使用同尺寸透明畫布，透過 `object-fit: contain` 維持比例；保留現有觸控範圍與版位。

僅更換左側三張圖及設定圖；其他九個元件、底部背景與產蛋倒數保持原狀。舊 UI 並不符合新參考外觀，這是明確未完成的範圍。新圖片不經 Phaser preload，不新增阻塞場景初始化的 await，沒有新增文字標籤。

## Step 4：驗證

### 功能回歸結果

| 入口／資料 | 隔離瀏覽器測試結果 |
| --- | --- |
| 每日任務、活動（禮包外觀）、圖鑑、設定 | 可點擊，顯示原本尚未開放提示，不切換場景 |

| 通知 | 開啟、讀取、領取／重試、刪除及未讀紅點更新通過 |
| 金幣、雞蛋、髒亂值 | registry 更新後同步顯示；雞蛋驗證四種雞合計，不使用素材示範數字 |
| 怪物與結算 | 戰鬥、尚未結算及結算重試時導覽持續隱藏，結束後恢復 |
| 按壓、觸控範圍 | 保留 0.95 按壓、至少 44px 觸控範圍 |
| 圖片 | 四張均成功 decode；與來源裁切範圍 RGBA 像素完全相同，只有透明留白 |
