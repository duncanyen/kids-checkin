# 遠古巨人

## 玩法與觸發

以玩家自己的雞舍 Lv.3 為最低條件，使用既有 `combatKills.wolf + combatKills.tiger`，每 50 次成功擊退預約一場挑戰（50、100、150、200…）。老鷹不計入，出售戰利品不會降低進度；缺少歷史擊退紀錄的舊存檔不以庫存倒推。

自家農場進入時檢查；拜訪農場則先完成既有怪物判定，未出現其他怪物時再檢查。蛇王、地鼠或其他怪物正在準備／戰鬥／結算時不疊加。尚未消耗的門檻保留到下次進入，不一次連續產生多場。

巨人素材先載入成功才透過交易預約挑戰。記錄 `id`、門檻、開始時間、到達時間及絕對期限；總長 70 秒，包含約 7 秒從右上方步行進場。進場期間也可攻擊。離開或重載不重置期限；過期後再次進入會補做一次失敗結算。沿用既有首領架構，畫面中的剩餘血量不逐擊寫入，重新載入以滿血恢復，但期限保持原值。

## 武器平衡

共用血量 36,000，使用整數傷害，混用武器也累積至同一條血量。

| 武器 | 每擊傷害 | 單一武器所需次數 |
| --- | ---: | ---: |
| 木棒 | 40 | 900 |
| 狼牙棒 | 45 | 800 |
| 雙手斧 | 60 | 600 |
| 大鐵槌 | 90 | 400 |
| 短弓 | 120 | 300 |
| 獵弓 | 180 | 200 |
| 聖騎士弓 | 240 | 150 |

沿用倉庫的近戰／弓箭裝備與拖曳瞄準介面，點擊巨人使用近戰，切換弓箭後只計實際命中的箭，不同時算近戰。既有其他怪物數值不變。武器圖鑑加入兩組次數。

## 動作與美術

參考使用者提供的苔蘚石巨人，以岩灰色、青色符文核心與厚重石拳製作透明 PNG。圖集為 8×4、共 32 格，含呼吸待機 8 格、右行 8 格、砸地 4 格、投石 4 格、受擊 3 格、崩解 4 格及遠古巨石圖示 1 格；左行翻轉右行。

遊戲內約 208×208 單位，採固定腳底原點，位於雞舍與菜園之間左右巡行。週期加入符文蓄能、朝母雞方向揮拳、砸地震波、朝附近母雞投石威嚇及短距側移；受擊與崩解有獨立動作。母雞沿用避讓路徑，攻擊只作威嚇，不額外扣雞、蛋或物品。減少動態效果偏好會關閉新增的輕微震屏。

- `assets/farm/giant-sheet.png`：原始透明美術圖集。
- `assets/farm/giant-sheet.json`：32 格 atlas，來源尺寸不同的格子統一為 224 單位畫布。
- `ancient_stone`：同圖集最後一格作為倉庫／商店物品圖示，不另載外部圖片。

## 獎勵與結算

- 勝利：`ancientStones +1`，先進倉庫，售價 600 金幣；倉庫已滿仍保留獎勵並顯示提醒。
- 失敗：只扣挑戰者最多 300 金幣，最低為 0；拜訪時不扣鄰居資產，不移除雞隻或蛋。
- 交易內核對挑戰 ID、期限及既有結果，同場重試／併發不重複發獎或扣款。晚於期限的勝利一律作失敗。
- 結算失敗顯示點擊重試；完成前封鎖再次收蛋／偷蛋／抓蟲及其他怪物，避免混入另一場。

新增選用資料沿用既有 `groups/{groupId}/users/{accountId}.farm`：`giantLastMilestone`、`giantChallenge`、`giantResults`（最近 32 場）、`ancientStones`。未批次變更正式存檔，未部署後端或權限規則。
