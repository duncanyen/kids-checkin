# Phase 6 — 精煉戰鬥平衡報告

日期：2026-11-27（台灣時間）。本報告全部為本機確定性模擬／程式預設值；未取得正式玩家或營運設定，不是正式帳單、實機DPS或真實每日收入。**沒有修改怪物HP、原始武器、攻速、倍率、掉落及活動規則。**

## 1. 模型與資料

以目前 `combat-rules.js`、`combat-damage.js`、`refinement-core.cjs`、`farm-combat.cjs`、`chests.cjs`、`refinement-stone-rewards.cjs` 的預設值，測試8種武器×9種怪物×4等級（+0/+3/+6/+9），共288列；180列相容組合各跑1000場，108列明示不可攻擊。種子固定，可重現。完整每擊傷害、DPS、平均／P50／P95有效擊數、TTK、時限勝率與收益情境在 [CSV](evidence/phase-06-2026-11-27/simulation/results.csv) 與 [JSON](evidence/phase-06-2026-11-27/simulation/results.json)。

標準情境：每秒2次有效命中、第一擊在0.5秒、全命中、單武器、每隻怪物起始無連擊。弓箭原本250ms最短發射間隔不變；近戰沒有新增冷卻。伺服器每秒20近戰／10遠程及burst4僅為反濫用上限，不是玩家實際輸入速度。模型另列protocolDamageCeilingPerSec，不能視為實際DPS。未強加進場動畫等待，因現有命中程式允許移動時擊中。

+0直接使用原V4函式；精煉使用新V5明確連擊cursor。單武器同序號 RNG／倍率相同，僅加成不同；混合武器切換清連擊，不能直接套用長期連打模型。所有比率是百分點相加，不逐級相乘。

## 4. 獎勵速度與每日產出情境

## 5. 平衡風險與建議（未改數值）

1. 高階武器打低階怪本來就可能一擊；+9大鐵槌開始跨過狼300HP的門檻，次數變化有台階，不能用HP/平均傷害完全替代離散模擬。
2. +9武士刀打巨人理想TTK約9.22秒，+0約14.85秒；聖騎士弓打飛鷹約由2.95擊降到2擊。數值有明顯成長，但是否過快需看實際每分鐘遇怪、命中率、移動與目標切換。
3. 精煉期望消耗（各級獨立、無保底、含失敗）約118,519.84金幣與62.123石；只看成功支出35,000／16會低估成本。解除只退成功成本10,500／8，失敗消耗不退，不是無損循環。
4. 沒有正式玩家金幣中位數/P90、活躍時間、武器分布、每怪勝率、遇怪率、箱設定或石庫存，不能結論經濟已平衡。應先蒐集每帳號/群組每小時金幣淨流入、掉箱/開箱、材料淨產出、精煉失敗率及操作時間分布。
5. 先在隔離/小範圍測試觀察，必要時提出新的活動節奏、非戰力金幣消耗或未來怪物內容方案；本階段不提高原怪HP、不降低原獎勵、不削弱已取得武器。任何新供給政策需另獲確認並採新版本，不追改舊箱。
6. 正式放行仍受Emulator/Rules、安全手勢驗證與既有時序測試限制，詳見 [Phase6報告](phase-06-report.md)。沒有部署或進入Phase7。
