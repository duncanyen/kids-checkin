## 2. 必須先決定的事項

| 決策 | 建議 | 為何需要確認 |
|---|---|---|
| 原始能力／精煉版本 | 出生／移轉原始能力快照＋本輪政策凍結 | 改變現行全體武器下場跟隨基礎設定的語意 |
| 小數 | 固定小數面板、新傷害協定、最後命中取整 | 木棒 +1=20.6，直接取整可能看不出每級成長 |
| 爆擊封頂 | 明確資格／上限；不能默默削弱 | 現有基礎設定可到100%，再加15個百分點超限 |
| 木棒／武士刀 | 木棒綁定個體、可讀；精煉與容量政策需定；武士刀不因精煉開賣 | 木棒目前沒數量、武士刀仍尚未開賣，但可有既有持有者 |
| 精煉石容量 | 是否每顆占格；滿倉解除整筆拒絕或待領 | 解除 +9 可退8顆石，原倉庫可能放不下 |
| 出售精煉武器 | 先明確解除再出售／棄置 | 不得偷偷替玩家銷毀精煉或自動退費造成重複 |
| 大量武器 | 安全即時批量＋grant ticket | 既有1,000份／20箱可能超過個體文件寫入上限 |
| 材料來源 | 按來源可控、只對新箱套新政策，先沒有資料的來源保持關閉 | 不把圖鑑／自動週獎當已存在，也不改舊箱內容 |
| 養成目標 | 取得14～28天安全聚合資料後決定來源配額 | 沒有正式餘額 P50/P90/P95／收入就不能宣稱平衡 |

前次需求的 +9 攻擊上限為 +50%（不是更早討論的2倍）、兩種率各+15個百分點；失敗不降級不毀損；保底預設關閉。這裡不修改該表，也不新增未確認的付費機制。

## 4. 未來放行指標

- 同一邏輯操作／個體 revision 不重複扣款、退款或發獎；跨裝置、過期結果與舊 epoch 均測。
- 所有舊種類武器數量一對一對應新個體；非武器金幣／存檔變化不被回蓋。
- 舊 PWA／舊區域不能新增舊堆疊或任意挑個體出售。
- 生效版本、抽樣、費用與返還使用同筆已接受意圖／歷史實際成本，Transaction 重試不重抽。
- 九種怪物限制、原時限與既有批次命中保留；每下攻擊增加 Firebase 請求為0。
- 倉庫按需分頁、不訂閱全量個體／歷史；量測實際每操作 reads/writes、Functions 時間與重試率，不能只報單一估算成本。
- 統計為可重建投影，不能拿它授權退款；日事件至少一次傳遞必須去重。

## 5. 回復與停止條件

任何階段發現未記錄 writer、正式 Rules 不符、來源數量不合法或遺漏舊箱交付，即停在 dry-run／唯讀，不以補造武器或放寬規則繼續。

功能停用不應讓玩家無法使用已取得的個體。staged 未啟用可回原資料；已發生新經濟交易後，停止新寫入、保留個體與帳本，經對帳修復／補償。不能整庫回灌舊備份抹掉新交易。
