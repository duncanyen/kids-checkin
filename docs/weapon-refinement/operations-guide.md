# 武器精煉營運操作指南（測試／發布準備）

日期：2026-11-28（台灣時間）。本階段沒有上線，正式開關全部false；本文不是操作正式帳號的授權。

## 1. 日常設定

獨立營運中心 → 武器精煉管理，不在玩家App。

- 管理員須有經目前Auth驗證的role=admin及refinementPermissions read／edit／publish／risk。只有read可查詢，不能繞其他模組改資產；同時操作原模組需opsLegacyAccess=true。
- 草稿編輯＋原因 → 儲存 → 驗證 → 閱讀前後值／歷史能力衝突／高風險項目 → 有權限者確認立即發布。
- +9攻擊增加最多50%、爆擊及連爆各15pp，不超上限。保底修改保留既有目標失敗次數，明示下次報價採新門檻。
- 歷史版本不編輯／刪除；回復建立新草稿／版本。設定發布不啟用正式玩家flag。
- 材料頁只調額外精煉石，原怪物寶箱掉落率到原寶箱管理調整；不偷改原金幣／戰利品。
- 解除比例預設30%金幣／50%精煉石，用本輪歷史成功投入，失敗消耗不退款。先查正式來源再談補償，不按新價格回推。

## 2. 玩家端流程（隔離驗收已測，正式未開放）

倉庫 → 武器個體 → 詳細資訊 → 精煉。每把同款武器各自ID／等級，已裝備可精煉但戰鬥期間衝突拒絕。畫面顯示目前與下一級能力、機率、資源，不需要回到首頁。

開始按鈕鎖定，同ID逾時查原結果；成功／失敗保持頁面，無自動連續精煉。解除有二次確認；直接出售保留原售價並告知不退精煉成本，不自動先解除。

精煉／解除結果不明時，保留登入scope與本機pending requestId，重新登入同群組確認原交易；換群組不能讀別scope結果。客服不要叫玩家清空本機憑證／pending來重按付款。

## 3. 交易追查

記錄player UID、groupId、instanceId、日期區間（台灣）、交易ID／設定版本。營運中心交易25筆／頁，多條件最多掃200候選，可能空頁但仍有下一頁。舊紀錄缺名稱／武器種類標未記錄，不從目前雞群或帳號暱稱猜測。

依序判斷：已完成收據 → 原結果；pending intent → 保持原ID確認；已拒絕 → 不扣新款；owner／scope或revision衝突 → 重新讀取原武器狀態，不放行舊報價。

## 4. 統計與查核

每日精煉人數按群組農場scope唯一；成功率帶樣本數，<100樣本不足，不能指控機率異常。設定成功率是交易當時的有效成功率平均（包含保底），不是目前設定。

- 金幣淨回收＝全部精煉金幣消耗－解除退款。
- 材料產出、消耗與返還分開，不能把解除返還當怪物新產出。
- 觀測金幣增加／減少是每筆餘額淨變化，不是毛收入／毛消費。
- 全服分布／參與率沒有完整分母時顯示缺資料；部分state不能推算全服+0。
- 金幣分位數只對所述的觀測樣本，不把最近有資產異動的farm等同所有登入活躍玩家。
- 戰鬥時間是新事件開戰至伺服器結算的elapsed，含請求等待，不是單純動畫秒數；缺舊時間欄位排除，不補0。

補算每批50來源，保存nextCursor續跑；快照每批50，固定jobId；交易／分片對帳每批100，固定jobId。matched只是所述觀測資料一致，concurrent-changes-retry需再跑，mismatch保留差異調查，不直接修改玩家。

## 5. 發布觀察

小規模時逐筆對帳與人工回報比低樣本錯誤率更重要。記錄每階段實際scope清單、人數、開始／結束、開關版本、所有可達區域、requestId及回復負責人。各階段至少包含足夠任務／寶箱／精煉／退款樣本及台灣日切；沒有樣本不要將空報表當正常。

同時看Auth登入、倉庫／裝備／戰鬥、Functions錯誤／冷暖延遲、Firestore讀寫與帳單、每有效動作的單位成本、金幣／材料流、武器數量與玩家回報。量化門檻見release-plan，尚待核准，不是已生效告警。

## 6. 事故

先停新精煉／解除，不刪武器／材料／能力；保留相容writer與原交易查詢。新材料來源需能與老寶箱兌付分開，目前正式adapter尚未具備，不能聲稱已有安全一鍵切換。詳細依 [rollback-runbook](rollback-runbook.md)。

## 7. 交接限制

未實作圖鑑里程碑／完整每週獎勵系統，不宣稱已回歸。未測實體iPhone／Android、真實雙裝置／行動網路、正式Rules／索引／IAM，且真實Emulator受403阻擋。管理員MFA仍選用；正式發布建議強化發布者MFA及最小IAM後再驗收。

## 2026-11-28：正式白名單與發布控制補充

工作目錄已加入「武器精煉 → 白名單與發布控制」。詳見 [release-control-report.md](release-control-report.md)。原先「只有 testEnvironment 路徑」的文字保留為歷史紀錄，最新正式准入改由伺服器主參數與精確農場 scope 控制；目前正式預設仍全部關閉、白名單空，未部署。

暫停使用此頁的「暫停新精煉與解除」，可選停止新的精煉石來源。不要刪私有武器、精煉狀態或舊箱快照。發布開關不是既得資產的撤銷開關，主開關關閉也保留既有能力與正常 V2 操作。日後重新開放要建立新版本，玩家重新取得報價。正式發布前必須先完成移轉對帳與對應參數發布，且另取逐步授權。
