# 大金剛首領

依本次「只限自己」需求解讀，大金剛只在自己家有效收蛋時遭遇，目標為目前群組的自己帳號。Lv.1 不抽首領、Lv.2 維持烈火龍 1/20；Lv.3 以上以單次 1–60 抽選，1–2 為大金剛、3–5 為烈火龍，其餘正常收蛋，因此機率分別精確為 1/30、1/20，不同時出現。沒有待收蛋、倉庫不足、戰鬥或結算未完成時不重抽；勝利後下一次收蛋直接收取。

## 美術與行動

- 依使用者提供的棕色大猩猩精靈參考，製作透明高解析圖集，包含奔跑、向右揮拳、受擊冒金星及倒地，每個動作四格。
- `gorilla-sheet.png` 為 1254×1254 透明 PNG，4×4 排列。`gorilla-sheet.json` 使用實際像素邊界（313／314 像素）及統一 314×314 sourceSize；每格 pivot 校正腳底，不能用固定 320 像素 spritesheet 切割。
- 畫面顯示尺寸 208×208，腳底對齊地面。由左下方奔向雞舍左側，10 秒抵達後向右揮拳；總期限 40 秒，命中不延長時間。母雞將大金剛列為避讓目標。
- 猩猩尖牙為獨立透明圖示 `gorilla-fang.png`，象牙白、琥珀根部、皮繩及葉片細節，與村落暖色美術搭配。

## 戰鬥與資料

`GORILLA_CONFIG`：血量 1000、進場 10000ms、總期限 40000ms、失敗罰金 100。武器沿用 `WEAPONS_CONFIG`，增加 `damageByEnemy.gorilla`：木棒 1、狼牙棒 5，因此分別需 1000、200 次命中。烈火龍仍使用原本的木棒 1、狼牙棒 10。新增武器可設定個別首領傷害，未設定時採用原本 damage。

烈火龍與大金剛共用 `BossEncounter` 的移動、時限、命中與結算呈現；各自保留獨立動畫、規則、結果紀錄與獎勵。大金剛結算只允許目前群組／自己帳號：

- 勝利：transaction 將 `farm.gorillaFangs` 加一，即使倉庫已滿仍保留首領獎勵並提示整理倉庫。物品計入容量，倉庫視為戰利品，不提供餵食；商店售出每件 300 金幣。
- 失敗：同一 transaction 清空 `farm.eggsReady`，扣除最多 100 金幣、不足歸零；同步消耗戰鬥期間已累積的產蛋時間，保留下一顆蛋的進度，避免舊蛋重新出現。
- `farm.gorillaResults` 保存最近 32 筆結算 ID，重試不重複發獎或扣款。暫時失敗提供點選重試。離開場景清除計時器、動畫及物件。

既有農場沒有 gorillaFangs 時視為零，不需要遷移正式資料。

測試使用實際 Phaser、記憶體 Firestore，不讀寫正式資料庫。涵蓋等級／精確機率、命中次數、四動作圖集、母雞避讓、勝利後收蛋、10+30 秒時限、自己家損失與金幣歸零、重試／冪等、滿倉獎勵、倉庫與 300 金幣販售，以及場景清理。烈火龍原有 600／60 次命中、收蛋與跨村結算另做回歸驗證。
