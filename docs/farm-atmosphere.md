# 咕咕村落：日夜與動態天氣

農莊沿用現有手繪底圖，增加環境光、燈光及少量天氣圖層。自己家與拜訪農莊共用 `attachFarmAtmosphere`，不改變收蛋、偷蛋、武器、獎勵或敵人時限。

## 時間與天氣

日夜以裝置當下時間換算台灣 UTC+8，與裝置顯示的時區無關。05:00–07:00 晨光、07:00–16:30 白晝、16:30–18:30 黃昏，其餘夜晚。以連續曲線漸變光色與亮度，跨午夜不跳色。夜晚保留操作視線，雞舍窗戶與既有燈柱加入暖光；晴夜有邊緣螢火蟲，烈火龍噴火時有局部暖光。

天氣是遊戲模擬，不讀取定位或外部氣象服務。使用固定版本種子、目標群組 ID、45 分鐘時間區間決定晴朗（45%）、多雲（30%）、小雨（18%）或薄霧（7%）。同村在相同時間得到相同結果，前往公開村落改用對方 groupId；不需寫入 Firestore。同種天氣可連續出現，判定不保證變天。切換區間後以 20 秒漸變，重整或重新進入也沿用相同進度。不同裝置須有正常的系統時間。

雨滴、飄葉、雲影與霧集中在場景邊緣，中央雨量視覺較淡。母雞下雨時偏向原本空地的上半部；遇敵則使用完整原有範圍與避障路徑，不躲進雞舍圖片。UI、對話框與敵人血條維持原本層級，天氣圖層不接收點擊。

## 內建效果與生命週期

遊戲上方僅顯示目前時段／天氣、台灣時間與下次判定時間，不提供玩家設定。日夜、雨滴、雲影、飄葉、霧氣與螢火蟲由遊戲直接啟用；不讀取舊版 `nexus-farm-atmosphere:{accountId}` 的偏好，因此曾選擇減少動態的玩家也能正常看見特效。環境音及其模組已移除，不載入或播放環境音。

離開農莊解除更新、頁面事件與圖層；重新進入依真實時間重建。生蛋計時回呼會先檢查場景及文字物件仍有效，避免場景關閉後更新已銷毀文字。頁面恢復、跨日與系統時間往回調整均重新計算。

圖形採固定 38 個粒子參數、5 個可重用 Graphics 圖層，不持續建立遊戲物件或載入新素材。特效至多約 30 FPS，背景分頁停止繪製。

## 驗證

```sh
node --test tests/farm-atmosphere.test.mjs
FARM_BASE_URL=http://127.0.0.1:8012 node tests/farm-atmosphere.cjs
FARM_BASE_URL=http://127.0.0.1:8012 node tests/farm-map.cjs
FARM_BASE_URL=http://127.0.0.1:8012 node tests/farm-hen-avoidance.cjs
```

核心測試涵蓋時區、四時段、跨日連續性、群組天氣與漸變權重。瀏覽器使用實際 Phaser 與模擬 Firebase，驗證四天氣、移除玩家設定、舊偏好不影響內建動畫、不載入環境音、母雞避雨、既有點擊、場景清理、跨村氣候及頁面恢復。所有測試不讀寫正式 Firebase。
