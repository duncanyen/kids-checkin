# 毒牙眼鏡蛇王

蛇王是擊殺里程碑魔王。玩家自己的雞舍達 Lv.2，且野狼、老虎、巨飛鷹的**累積成功擊殺合計**達到 100、200、300……時，下一次進入自己的農場或拜訪農場會優先觸發，收蛋操作也會補查。使用自己的雞舍等級，不使用被拜訪者的等級；蛇王不與隨機怪物同時生成。每個百殺里程碑只挑戰一次，勝負皆算已使用。一次跨過數個里程碑時按順序處理，不跳過。

舊存檔沒有累積擊殺紀錄，且戰利品可出售，無法從持有數量可靠還原歷史擊殺。因此更新後才開始記錄 `farm.combatKills.{wolf,tiger,eagle}`，不重設任何既有農場資料。擊殺紀錄與普通怪物的戰利品使用同一筆交易；即使倉庫滿而無法獲得普通戰利品，成功擊殺仍計入。`combatKillReceipts` 防止同一場重複累加，出售物品不扣擊殺數。

## 戰鬥

- 角色以紫金配色、王冠及紅眼呈現，畫面尺寸 160 × 160 世界單位，實際身體保留透明留白。手機與橫向畫面依既有相機比例縮放。
- 從畫面右側沿地面爬入，8 秒後抵達雞舍與菜園之間，左右巡行，每 5 秒向下作勢攻擊。攻擊是視覺威嚇，不扣母雞或蛋。
- 從觸發起共 50 秒，包含進場時間。`cobraChallenge` 保存挑戰 ID、里程碑、進場結束時間與絕對截止時間；離開、重新載入或跨村拜訪會沿用原截止時間。離線或關閉頁面跨過期限，下一次進場補結算，不延長時間。
- 近戰點擊蛇王；弓箭需先切換、拖曳瞄準並命中。弓模式下點擊蛇王不會另算近戰傷害。弓操作保留 Android 底部 80 螢幕像素的完整拉弓餘裕。

| 武器 | 擊殺命中次數 |
| --- | ---: |
| 木棒 | 500 |
| 狼牙棒 | 300 |
| 雙手斧 | 200 |
| 短弓 | 60 |
| 獵弓 | 40 |
| 聖騎士弓 | 20 |

勝利保證獲得一件「眼鏡蛇王毒牙」，存入 `farm.cobraFangs`，佔一格倉庫；倉庫已滿也保留獎勵並提示整理。在商店「賣出／其他」可每件賣得 600 金幣。毒牙使用獨立繪製的透明物品圖。

逾時失敗僅扣**挑戰者本人**最多 200 金幣，不足時歸零。自己的母雞、雞蛋與庫存、被拜訪者的所有資料皆不因蛇王失敗受損。結算交易會再次檢查截止時間，截止時才送達的勝利會按逾時處理。`cobraResults` 保存最近 32 場結算收據，重試和並行頁面不重複獎勵或扣款。

下載素材完成後才以交易預約里程碑及開始計時，下載失敗可重試，不消耗里程碑。正在戰鬥或結算時阻擋收蛋與偷蛋。場景離開時移除動畫、計時器、弓箭輸入及更新回呼。
