# 大野狼精靈與空地巡走

使用參照提供圖樣製作的透明 PNG 圖集（`assets/farm/wolf-sheet.png` 與 JSON），行走、撲咬、受擊與倒地各 4 格。每格保留透明取樣邊界，腳底對齊，排除零散裁切殘影。向左行走／攻擊使用水平翻轉。

大野狼從目前視窗右下方往上走，10 秒進入雞舍與菜園之間母雞活動的空地，再由右向左開始巡走，抵達邊界時折返。與老虎共用空地範圍及視窗切換定位；老虎仍從左下方進場。

巡走時每 5 秒暫停，轉向最近的可見母雞播放撲咬；動畫結束後恢復巡走。沒有母雞時繼續巡走。攻擊只是視覺效果，不新增母雞損失、偷蛋或扣款。

原有血量、武器傷害、狼牙獎勵、倉庫限制及單次結算不變。從出現起 60 秒未擊退，沿用原本偷走目標雞舍一顆可收成蛋的規則；玩家受擊操作不會延長期限。擊退、逃走或離開場景時清除巡走及攻擊計時。

驗證：`node --test tests/*.test.mjs tests/*.test.cjs`；啟動本機靜態伺服器後，以 `FARM_BASE_URL=http://127.0.0.1:8012 node tests/farm-predator-timing.cjs` 驗證兩種動物的進場方向、左右巡走、最近母雞攻擊、視窗切換與原有期限，並以 `tests/farm-actors.cjs` 驗證受擊、擊退和防止重複結算。
