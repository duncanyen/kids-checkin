# 固定期間偷蛋排行榜

右下通知信封上方新增木質獎盃 SVG 按鈕，開啟偷蛋排行榜，顯示公開村落玩家 Top 10、玩家名稱、村落及成功偷蛋顆數。開啟排行榜暫停遊戲操作，關閉／Escape 還原；支援手機直向、橫向及桌面捲動。

本期記錄時間固定為 **2026/11/9 00:00:00 至 2026/11/15 00:00:00，Asia/Taipei**；包含開始時間，不包含截止那一刻。期間外不再加計，但截止後仍可查看累積成績。視窗顯示「尚未開始／記錄中／已截止」與完整期間，跨越開始或截止點時重讀。下方公告顯示「截止後依排名發放獎勵，這次除金幣外還會有額外驚喜獎品，請大家繼續努力偷蛋，爭取好成績」。本次只更新公告，沒有新增自動發獎／領獎流程。

每次成功偷一顆任意品種的蛋，在同一筆偷蛋 transaction 增加來源農場的 `farm.stolenEggs20261109`。分類獨立於舊 stolenEggsTotal，不混用舊累計；交易前沿用農場 HTTP Date 校時，交易重試重新檢查時窗。來源群組必須在交易中讀取為公開；被護衛犬攔截、冷卻、空雞舍、滿倉、交易失敗及期間外都不加計。一般偷蛋及匿名訪客通知照常保留。

排行以 groupId＋accountId 分開計算，同一帳號在不同群組會各自列名、各自累積，不再跨群組加總；玩家名稱下方顯示群組名稱。改名不影響身分；同分依 accountId、groupId 固定排序。僅列出有正數紀錄、帳號未移除且仍屬於該公開村落的玩家；讀取途中村落轉私人或退出成員者不納入。私人村落成員可以查看公開排行，但私人村落的偷蛋不計數。資料於開啟或手動重新整理時讀取，最多同時查四個村落，不持續輪詢全村落。

本期使用新欄位 `stolenEggs20261109` 達成所有玩家本期歸零：缺少該欄位即視為 0，首次成功偷蛋記為 1；上期 `stolenEggs20261102` 與舊累計保留供查考，不參與本期計分或排行。新版本發布後玩家需重新整理村落；不回填發布前的次數。本功能沒有新增 Firebase Functions 或排程，不需要後端部署或批次改寫所有玩家存檔。

驗證：`node tests/farm-ranking.test.mjs` 檢查台灣時間邊界、固定期間、公開村落資格、改名可用的群組＋固定帳號區隔、Top 10、同分及舊累計隔離；`FARM_BASE_URL=http://127.0.0.1:8012 node tests/farm-mail-browser.cjs` 使用實際 Phaser 與隔離 Firebase，檢查成功／失敗偷蛋、通知上方入口、活動日期、排行、手機與桌面版面及信箱不受影響。
