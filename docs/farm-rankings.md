# 固定期間偷蛋排行榜

右下通知信封上方新增木質獎盃 SVG 按鈕，開啟偷蛋排行榜，顯示公開村落玩家 Top 10、玩家名稱、村落及成功偷蛋顆數。開啟排行榜暫停遊戲操作，關閉／Escape 還原；支援手機直向、橫向及桌面捲動。

本期記錄時間固定為 **2026/11/2 00:00:00 至 2026/11/9 01:00:00，Asia/Taipei**；包含開始時間，不包含截止那一刻。期間外不再加計，但截止後仍可查看累積成績。視窗顯示「尚未開始／記錄中／已截止」與完整期間，跨越開始或截止點時重讀。沒有每週歸零、排程、系統發獎或領獎功能。

每次成功偷一顆任意品種的蛋，在同一筆偷蛋 transaction 增加來源農場的 `farm.stolenEggs20261102`。分類獨立於舊 stolenEggsTotal，不混用舊累計；交易前沿用農場 HTTP Date 校時，交易重試重新檢查時窗。來源群組必須在交易中讀取為公開；被護衛犬攔截、冷卻、空雞舍、滿倉、交易失敗及期間外都不加計。一般偷蛋及匿名訪客通知照常保留。

排行使用固定 accountId 合併玩家在各公開村落的計數，名稱變更不分成不同玩家；同分依 accountId 固定排序。僅列出有正數紀錄、帳號未移除且仍屬於該公開村落的玩家；讀取途中村落轉私人或退出成員者不納入。私人村落成員可以查看公開排行，但私人村落的偷蛋不計數。資料於開啟或手動重新整理時讀取，最多同時查四個村落，不持續輪詢全村落。

這是從功能上線開始收集的獨立欄位。部署前只有累計或匿名訪客紀錄，無法可靠重建 11/2 零時至部署前的個人次數；不自動回填、改寫舊存檔或捏造紀錄。舊存檔沒有本期欄位時視為 0。本功能沒有新增 Firebase Functions 或排程，不需要部署先前已移除的週賽函式。

驗證：`node tests/farm-ranking.test.mjs` 檢查台灣時間邊界、固定期間、公開村落資格、改名可用的固定帳號聚合、Top 10、同分及舊累計隔離；`FARM_BASE_URL=http://127.0.0.1:8012 node tests/farm-mail-browser.cjs` 使用實際 Phaser 與隔離 Firebase，檢查成功／失敗偷蛋、通知上方入口、活動日期、排行、手機與桌面版面及信箱不受影響。
