# 咕咕村落排行榜

通知信封上方新增相同木質風格的獎盃圖示，點入開啟排行榜。初始分類是「偷蛋王」，依成功偷蛋總數顯示公開村落玩家 Top 10，附玩家名字、村落及顆數。列表可捲動，橫向手機也能查看全部名次；關閉或 Escape 還原遊戲輸入。重新整理按鈕重新讀取最新資料，不在背景輪詢全部村落。

每次成功偷到任何品種的一顆蛋，在原本偷蛋交易內將偷蛋者的 `farm.stolenEggsTotal` 加一。被狗攔截、冷卻、空雞舍、倉庫已滿及失敗交易都不加計；交易重試不重複增加。缺少此欄位視為零。舊版沒有偷蛋計數且訪客通知匿名，因此不推算或捏造歷史次數，自此次更新開始累計。

只彙整 `farmVillageVisibility: public` 村落的現有成員及有效玩家資料。私人村落、已離開的成員及 `role: removed` 玩家不參與；讀取後重新確認村落公開狀態與成員清單。同一帳號在不同公開村落的存檔次數相加；同分以固定帳號排序，最多列十位，零顆不入榜。沿用跨村瀏覽的雙方公開條件，目前所在村落封閉時提示先設為公開。

`ranking-core.js` 的 `FARM_RANKINGS` 是可擴充的分類登錄表，定義名稱、計數欄位、單位及說明；介面依登錄表產生分頁。資料讀取按村落分組、限制同時讀取數量，沒有新增後端部署需求。與目前金幣等遊戲計數相同，這是客戶端交易流程，不提供防修改客戶端的伺服器競賽認證。

驗證：`node --test tests/farm-ranking.test.mjs` 與 `FARM_BASE_URL=http://127.0.0.1:8012 node tests/farm-mail-browser.cjs`。瀏覽器使用隔離 Firebase 資料，涵蓋成功偷蛋計數、失敗不加計、私人村落排除、跨公開村落合併、Top 10 及手機／桌面／橫向版面。
