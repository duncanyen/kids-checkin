# 柯基犬活動、坐下與睡眠規則

日期：2026-11-10。

## 本次行為

| 階段 | 規則 |
| --- | --- |
| 奔跑 | 110 → 77 場景單位／秒，降低 30%；動畫 10 → 7 FPS |
| 返程步行 | 75 → 52.5 場景單位／秒；動畫 6 → 4.2 FPS |
| 一次活動 | 約 60 秒，沿可見雞群外圍繞行，每段轉向約 40–60 度，避免任意大幅折返 |
| 坐下賣萌 | 活動第 20 與 40 秒，各坐下約 4 秒，使用現有坐姿／吐舌格，不播放警戒吠叫格 |
| 回家 | 活動結束後完整走回雞舍旁，不把尚未走完的返程截斷 |
| 睡眠 | **抵達雞舍後**才開始 60 秒，使用閉眼呼吸格；睡滿才重新出門 |
| 無放風雞 | 在既有雞群活動範圍巡邏 |

60 秒活動包含兩次坐下，睡眠不包含返程。因此延續約一半時間在外活動的風格，但不再使用舊 15 秒跑／15 秒返程休息模式。

睡覺與坐下均不降低原 40% 攔截機率、2 小時禁偷或租約效果。雞隻仍避讓柯基，原下蛋流程不變。

## 中斷與生命週期

- 吠叫警戒：暫停剩餘活動／坐下／睡眠時間，警戒結束後續接，不取消午睡，也不重設為另一個完整 60 秒。
- 改變畫面尺寸：重新對位睡眠點／路徑，但保留原睡眠截止時間。
- 進商店、倉庫再返回：同一 Phaser.Game 工作階段以租約 ID 保存行為狀態，不會每次重新睡一分鐘或提前出門。
- 解除、到期、換犬：沿用既有清除精靈、計時器及 tween 的流程，移除舊租約行為。
- 行為狀態僅在該遊戲工作階段記憶體中；整頁重新載入或關閉瀏覽器後重新建立，不寫 Firebase，也不作為經濟或權限依據。

## 程式

- `js/farm/corgi-routine.js`：純時間狀態機、77／52.5 速度、20／40 秒坐下、到家後 60 秒睡眠、警戒暫停，以及依 Game／租約保存狀態。
- `js/farm/guard-dog-art.js`：柯基專用活動流程及既有動畫格重用，保留其他犬種原流程。
- `js/farm/guard-dog-ui.js`：租用視窗顯示新版說明。
- `js/farm/guard-dog-core.js`：僅補相容性說明，金額／機率／租期設定不變；舊相容函式仍可供舊版本呼叫，現行柯基不再透過它選擇動作。

沒有修改素材圖、Firebase schema、護衛 API、Rules 或其他犬種數值。本次為前端表現變更；若首次新增柯基所需的後端版本已部署，這次不需再次部署 Functions。
