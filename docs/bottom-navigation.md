# 底部功能導覽

主頁改為貼齊螢幕底部的橫向導覽，維持共用線條 SVG 圖示，增加文字與目前頁面的主題色標記，並保留 iPhone 安全區。固定「首頁」，另可選最多六個已開放功能，因此最多顯示七個入口。

## 個人設定

「個人設定 → 底部導覽列」可勾選、取消、調整順序、還原與儲存。選滿六個後其餘未勾選項目停用；可先取消一個再改選。可全部取消，只保留首頁。

以 `userSettings/{accountId}` 合併儲存 `navigation: { version: 1, items: [...] }`。不修改主題、卡片排序或卡片顯示設定。僅顯示目前帳號管理者已開放的功能；主頁卡片顯示開關與底部捷徑各自設定。未設定的舊帳號會依原有排序與開放清單選前六個，避免第一次載入就寫入預設設定。

主頁及設定頁沿用原有個人設定讀取，不增加常駐資料庫監聽；功能頁讀取帳號隔離的 `nexus.navigation.v1:{accountId}` 本機快取。雲端讀取失敗沿用本機偏好，不把預設值覆蓋回雲端。儲存失敗保留選擇並提供重試。跨裝置先進入主頁或個人設定取得帳號雲端偏好。

## 路由行為

| 進入方式／頁面 | 返回主選單 | 共用底部導覽 |
| --- | --- | --- |
| 主頁 | 不適用 | 顯示 |
| 底部導覽進入行事曆、聊天室、記帳本、Photo Dump、許願牆、待辦、吃什麼、打卡 | 隱藏 | 保留 |
| 功能卡、側選單或直接網址進入上述功能 | 顯示 | 沿用原本頁面，不新增共用導覽 |
| 底部導覽進入遊戲區 | 顯示 | 隱藏，直接顯示遊戲大廳 |

使用同站一般連結 `頁面.html?nav=1` 標記導覽列入口，跨頁會重新掛載相同導覽，不使用 `window.open`。返回按鈕只標記主選單返回，不隱藏聊天室內返回群組列表、月曆換月、彈窗取消等操作。記帳本顯示名稱已統一為「記帳本」。

待辦固定新增列與相簿發文按鈕避開底部導覽；聊天室與行事曆的可捲動內容保留導覽高度。「吃什麼」原有首頁／投票／結果／管理四個控制移至日期列後、內容前，保留全部功能，避免兩列固定導覽重疊。

## 維護與驗證

- `navigation-config.js`：功能清單、上限、舊設定回退、權限篩選與快取。
- `app-navigation.js`／`app-navigation.css`：共用導覽、路由入口與版面保留空間，不初始化另一個 Firebase app。
- `navigation-settings.js`／`navigation-settings.css`：選擇、排序、原子合併寫入與重試提示。
- `node --test tests/navigation.test.mjs`：上限、去重、未知項目、順序與開放清單篩選。
- `node tests/navigation-browser.cjs`：真實功能頁、儲存失敗與重試、欄位保留、導覽切換、返回按鈕、選取狀態、操作按鈕不被遮住、遊戲大廳例外與帳號隔離。Firebase 使用隔離測試資料，不寫入正式系統。
