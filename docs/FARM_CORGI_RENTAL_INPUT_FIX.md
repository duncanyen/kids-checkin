# 柯基犬 7 天租用選項修正

## 問題與原因

在真實 Phaser 商店、390×844 觸控視窗，經護衛犬分類點選柯基犬，再點「7 天」，修正前可重現輸入值變回 `1`（預期為 `7`）。

DOM 租用視窗沒有暫停底下 ShopScene 的輸入，且觸控事件會繼續傳到 Phaser。按天數按鈕也可能命中後面的犬種商品，重新開啟另一個租用視窗，因而重設天數及犬種。

## 修正

`guard-dog-ui.js` 的共用護衛犬視窗現在：

- 開窗時保存並停用目前場景輸入。
- 遮罩攔住 pointer／touch／click／wheel 事件的傳遞，保留視窗自身的輸入、按鈕及捲動。
- 取消、Escape、操作成功或場景離開時，冪等清理 DOM／監聽器，還原先前輸入狀態並清除視窗參照。

沒有更改租金、犬種、租用天數計算、倉庫啟用方式或後端交易。

## 驗證

- 真實 Phaser + 既有後端服務 + 隔離 Firebase SDK，從遊戲原有「商店 → 護衛犬 → 柯基犬」入口操作，使用觸控事件。
- 320×568、390×844、430×932：反覆選 7／1／7 天，犬種保持柯基犬，分別為 500／100／500 金幣；選天數不增加後端請求。
- 取消不扣款；金幣不足時不新增租約，視窗保持原犬種／7 天，取消後恢復商店輸入。
- 確認租用只取得一隻 `corgi`、7 天、扣 500 金幣、尚未啟用的倉庫租約。
- Escape、場景離開、重回商店與租用其他犬種正常。
- 護衛犬規則、後端服務及場景清理專項單元測試 **22/22 通過**。

本次沒有跑完整 Emulator；此次未變更後端程式，發布前端即可，不需部署 Functions。尚未推送 GitHub 或更新正式網站。
