# 行事曆進入與新增流程

首頁行程卡帶入 calendar_target_date 時保留完整年月日，不再重設為每月一號。讀取到該日期有可見行程才自動開啟明細；沒有行程則只定位日期，不彈出明細或新增表單。日期參數讀取後清除，後續即時更新不會重新觸發導航。

日視圖沿用完整的目前日期；點選月／週格子的日期，也會更新後續切換日視圖所用日期。月切換保留原日，遇到較短月份則限制到該月最後一天（例如 1/31 → 2/28），避免 Date.setMonth 溢位跳月。

右下方圓形 SVG「+」直接開啟新增行程表單，日期永遠預設今天，日期欄為第一項，可改為其他日期；分類、權限、全天／時間、提醒與備註沿用原表單。從「+」取消直接關閉，從日期明細新增或編輯時取消返回該日清單。儲存成功才定位到寫入日期，失敗保留表單內容；編輯也可移動日期。按鈕避開底部導覽列。

驗證：`node tests/calendar-flow-browser.cjs` 使用隔離資料與台灣時區，涵蓋空／有行程導航、日視圖日期、預設今天、日期欄、取消、跨月新增、編輯、失敗重試、月底切換及 320／390／768px 按鈕位置；既有 `node tests/calendar-icons-browser.cjs` 回歸原有分類與編輯刪除。
