## 畫面

沿用現有手繪農莊與角色資產，在自家／拜訪雞舍增加笑臉南瓜燈、橘紫屋簷旗串、可愛幽靈吊飾與邊緣落葉。村落列表只在側邊加小幽靈及底角南瓜，保留村落搜尋與分頁。白天保留綠色草地，夜間由既有氣候系統配合稍強的琥珀光暈。幽靈小幅搖擺與燈光呼吸支援減少動態效果。

裝飾不接收點擊、不進入碰撞或動物威脅清單。手機直向與橫向全景採兩份底圖原生座標配置，避開門匾、蛋及全部 42 顆高麗菜；原底圖、經濟、雞群路線與護衛犬租期都不修改。

`assets/farm/halloween-2026.png/json` 為透明圖集，包含 6 組獨立美工。由已核准概念稿衍生同風格素材，再做完整裁切、透明內邊界及圖格間距，避免鄰格殘影。圖集約 104 KiB，只有活動期間進入上述場景才按需載入一次、跨場景共用；排除 `CORE_ASSETS` 及常態 `ALL_ASSETS`，倉庫／商店與截止後的新訪客不會為此額外下載圖集。美術補載失敗不阻擋農莊操作，30 秒後可重試。

## 自動結束

- 獨立場景容器疊加，不替換正常底圖，到期直接銷毀全部裝飾與光暈。
- 使用毫秒時間界線，每個場景 frame 先檢查截止，另設原生瀏覽器邊界 timeout，與 Phaser 的遊戲時間倍率／暫停分開。
- 切換場景、恢復前景、pageshow 及網路恢復都重新確認。背景頁面受瀏覽器排程限制時，在恢復可見時先檢查並移除；不需重新整理或在 11/1 再人工發版。
- 時鐘以同來源 `farmgame.html` 的不快取 HEAD 回應 `Date` 校正，每 5 分鐘至多自動取樣一次，前景恢復可強制重校。完全不寫入遊戲／正式資料庫。
- HTTP Date 是秒級訊號，以該秒中點加半個往返時間估算伺服器時間，精度受 HTTP 時間解析度、網路延遲及瀏覽器排程影響，不能宣稱硬即時毫秒保證。截止常數本身精確設定為台灣 11/1 00:00:00。
- 校正後使用 monotonic elapsed time 與往前的 wall elapsed time，避免裝置時鐘往回調延長佈置，也涵蓋系統睡眠期間 performance clock 暫停的裝置。離線時沿用估算；完成一次可信校正且到期後，延遲或較舊的 HTTP 回應不會讓裝飾復活。
- 未成功取到 HTTP Date 時暫用裝置時間起算。沒有可信網路時間且裝置原始時鐘錯誤時，無法保證真實時間準確；重新連線後校正。一般在線使用不依賴裝置時區。
- 圖集下載跨過截止或場景已離開時，完成下載也不再建立裝飾。瀏覽器快取留下圖片不代表活動繼續啟用。
