# 農場物品美術

八種物品改用同一套手繪 PNG：母雞蛋 `egg.png`、烏骨雞蛋 `silkie-egg.png`、布雷斯雞蛋 `bresse-egg.png`、金幣 `coin.png`、菜蟲 `worm.png`、蚯蚓 `earthworm.png`、狼牙 `wolf-fang.png`、虎皮 `tiger-pelt.png`。

沿用現有農場及武器素材的暖色明暗、棕色輪廓與柔和高光。三種蛋分別使用暖象牙白、帶細斑點的奶油色、帶淡藍陰影的珍珠白；烏骨雞蛋不畫成黑色。每張圖為 128×128、透明背景並保留安全邊界，以相同留白比例在商店、倉庫縮放到原有卡片尺寸。

保留原本 texture key，由共用 asset manifest 載入，移除對應的文字矩陣產圖。商店與倉庫使用同一份素材；首頁金幣、商店餘額與菜園抓蟲提示也採用相同圖示。首頁只先載入蛋、金幣、菜蟲與蚯蚓，其餘在功能素材載入時取得。物品數量、價格、交易、餵食和獎勵規則未修改。

雞舍收成蛋使用 `scenery.js` 的共用建立與定位方法。直向背景定位在原圖 `(334,358)` 的門內稻草；橫向背景獨立定位在原圖 `(1034,254)`，不套用一般地標的垂直插值，以免落到斜坡上。切換視窗時同步重設座標與顯示尺寸，維持至少 44 像素的點擊範圍。自家收蛋與拜訪偷蛋沿用原本回呼。

驗證包括：物品透明邊界與八種獨立美術、商店／倉庫實際載入圖片、自家／拜訪雞舍兩張背景的門內定位與點擊、漸進載入失敗重試及存檔狀態。對應測試為 `farm-item-art.test.cjs`、`farm-item-categories.cjs`、`farm-map.cjs`、`farm-loading-browser.cjs`、`farm-save-browser.cjs`。
