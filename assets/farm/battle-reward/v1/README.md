# 咕咕村落｜戰鬥勝利獎勵視窗

用 assets/ 內的透明 PNG 組裝，preview.png 為手機版設計稿，manifest.json 含尺寸與配置。沿用收蛋或偷蛋結果視窗的遮罩與關閉流程。標題、怪物名稱、道具名稱和數量透過現有介面動態顯示。

- 接在既有擊退怪物及結算成功的事件，同一筆結果只顯示一次。彈窗標題是「戰鬥勝利」，下方顯示「擊退 {monsterName}」。
- 「本次戰利品」預留三列，三列共用同一張底圖。依既有掉落規則，目前只填第一列。第二、三列只顯示低對比空底板，不加文字、道具圖案或互動。日後有多筆獎勵時，依結算陣列填入可用欄位，無須改畫面。
- 巨飛鷹與巨鷹羽毛是示例素材。按真實怪物 ID 與道具 ID 配對，其他項目優先用遊戲已有的立繪與圖示。缺少對應圖片時保留真實名稱及數量。
- 確認道具確實已入庫後才顯示「已放入倉庫」。彈窗省略售價與出售提示，商店價格及既有掉落規則照舊。
- 「確定」與「關閉」只關閉視窗，不再次發獎或累加任務。使用既有交易結果更新倉庫，避免同一場戰鬥出現重複浮字與彈窗。其他戰鬥提示沿用現有行為。
- 驗收巨飛鷹掉落一項、不同怪物的道具對應、長道具名稱、手機安全區、重複戰鬥事件，以及一至三項的版面。多項測試使用測試資料，不改正式掉落規則。
