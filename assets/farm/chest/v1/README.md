# 咕咕村落｜木質寶箱與開箱動畫

- 戰鬥結果與倉庫物品格共用 `chest_inventory_icon.png`（合蓋圖示）。
- 開箱使用 `chest_open_spritesheet.png`（2048 × 1024、4 欄 × 2 列、每格 512 × 512 RGBA）。`frames/` 另附八張同尺寸的獨立 PNG。
- Phaser 的 frameWidth 和 frameHeight 均為 512。格序由左到右、由上到下，編號 0–7。整組使用固定原點 (0.5, 0.78125)，不用逐格裁切。
- 依 manifest.json 的各格時長播放一次，總長 900 ms。在第 4 格揭曉結果，停在第 7 格等玩家關閉。`chest_open_static.png` 供靜態開箱或減少動態模式使用。GIF 為循環展示，首尾停留較久。
- 玩家在倉庫點開寶箱時沿用既有倉庫與道具結算流程。收到成功結算後播放完整開箱並顯示實際獎勵。重複點擊、跳過動畫及關閉視窗只影響畫面，不重複結算。動畫中的金幣固定用作視覺表現，實際獎勵圖示、名稱、數量由結果帶入。
- 戰鬥掉落機率、寶箱內容及消耗規則沿用專案實際設定。這份包提供圖檔與動畫配置，圖上不嵌入獎勵金額或名稱。
