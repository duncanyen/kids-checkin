# 咕咕村落｜協助打掃雞舍確認視窗

請用這包素材替換拜訪他人村落時既有的打掃確認畫面。沿用現有入口、遮罩、焦點與返回流程，以 preview.png 為版面參考，使用 assets/ 內的獨立透明 PNG 組合。manifest.json 提供原始尺寸、素材用途與預覽定位。預覽是對照用的靜態設計稿。

- 標題為「打掃雞舍」。內文用「{username}的雞舍有點髒亂，是否要幫忙打掃雞舍？」。將現在拜訪的玩家名稱作為純文字帶入，可換行並保留手機安全區。「小麥村長」是預覽示例。
- 左側淺木色按鈕疊上「否」，右側綠色按鈕疊上「是」。用既有可操作的按鈕元件承載，觸控區至少約 44 CSS px 高。長名字出現時可讓內文多行，保持按鈕可操作。
- 「否」關閉視窗並返回目前拜訪的村落，無清潔寫入。「是」呼叫現有協助打掃流程一次，等待期間避免重複提交。成功或失敗依既有結果顯示。
- 沿用原本的打掃判定、任務計數與資料更新。從現有遊戲入口驗證長玩家名稱、小螢幕、「否」、成功、「是」快速連點與失敗處理。
